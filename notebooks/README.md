# Notebooks

Recommended notebook order:

1. `01_dataset_qc.ipynb` — inspect standardized h5ad metadata and cell-type labels.
2. `02_landscape_estimation.ipynb` — inspect density, quasi-potential, and microstate choices.
3. `03_flux_entropy.ipynb` — inspect transition matrices, probability currents, and entropy-production-like scores.
4. `04_biological_attribution.ipynb` — compare high-flux transitions against modules, DE genes, and prior beta-cell dysfunction signatures.
5. `05_validation.ipynb` — repeat analysis in GSE153855/E-MTAB-5061/GSE81608.

The command-line scripts are the reproducibility backbone. Notebooks should be exploratory or explanatory only.
